# Дослідження джерел ринкових цін (28 листопада 2026)

Підготовка до E4. Усе читається з відкритих джерел; нічого не записується в базу застосунку. Висновки й рішення: `PLAN/DIPLOMA_NOTES.md`, розділ «Джерела ринкових цін», і `docs/METHODOLOGY.md`.

## Prozorro: де лежать ціни за одиницю

```powershell
back-end\.venv\Scripts\python.exe eval\research_prozorro_prices.py --target 200                 # вибірка з усіх процедур (переважно reporting)
back-end\.venv\Scripts\python.exe eval\research_prozorro_prices.py --target 200 --competitive   # без reporting, зі читанням /contracts/{id}
```

Файли: `prozorro_prices_sample.json` і `prozorro_prices_sample_competitive.json` (по одному рядку на позицію: тип процедури, група CPV, чи є ціна за одиницю в тендері, чи виводиться з вартості, чи є вона в позиціях договору). Вибірка: завершені тендери груп CPV 15, 30, 39, 44 з чотирьох вікон стрічки 2026 року (лютий, середина березня, травень, середина червня); не випадкова вибірка за весь час.

Результат (конкурентні процедури, 201 тендер, 862 позиції): ціна за одиницю в позиціях договору (`/contracts/{id}`, `items[].unit.value.amount`) є для **100 %** позицій `priceQuotation` (електронний каталог, 433 позиції), **3 %** `aboveThreshold` (399) і 0 % `belowThreshold` (30); за групами CPV 15: 97 %, 30: 74 %, 44: 29 %, 39: 20 % (залежить від частки каталогу). У процедурі `reporting` (210 тендерів, 417 позицій) ціна за одиницю явно в тендері для 14 % позицій, виводиться (одна позиція: вартість нагороди ÷ кількість) ще для 32 %. У нагородах (`awards`) окремого поля ціни за одиницю немає.

## Держстат: середні споживчі ціни

```powershell
back-end\.venv\Scripts\python.exe eval\research_derzhstat_prices.py
```

Файли: `derzhstat_names.json` (назви товарів і регіонів, витягнуті з великого файлу «136.csv» того самого набору; сам файл 520 МБ не зберігається), `derzhstat_avg_prices.csv`. Набір: https://data.gov.ua/dataset/c1cd8f39-c2ee-4f20-8c8a-6cdde6e6f343 (ліцензія Creative Commons Attribution).

Результат: показник `AVG_CONS_PRCS` (середні споживчі ціни) є: **55 товарів, 26 територіальних розрізів (області й національний), місячні ряди з січня 2017 до березня 2026**. Це переважно продукти (крупи, хліб, борошно, м'ясо, молочні, яйця, олія, овочі, цукор), пальне, кілька ліків і послуг; канцтоварів, будматеріалів, інструментів і меблів немає. Останнє оновлення файлу 11 травня 2026, нових версій після нього немає. Окремо в наборі є місячні індекси споживчих цін для індексації цін минулих періодів.
